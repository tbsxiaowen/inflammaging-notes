# 图标文件说明

这个文件夹需要包含以下图标文件：

## 必需图标

- `icon16.png` - 16x16 像素，用于扩展列表和书签栏
- `icon48.png` - 48x48 像素，用于扩展管理页面
- `icon128.png` - 128x128 像素，用于Chrome网上应用店

## 图标设计建议

- 使用简洁的设计，在小尺寸下仍然清晰
- 建议使用YouTube红色 (#FF0000) 作为主色调
- 可以包含字幕或翻译相关的视觉元素
- 确保在不同背景下都有良好的可见性

## 创建方法

1. 使用在线图标生成器（如 favicon.io）
2. 使用设计软件（如 Figma, Sketch, Photoshop）
3. 使用AI图像生成工具
4. 从图标库下载并调整尺寸

## 临时解决方案

如果暂时没有图标，可以：
1. 使用任何现有的图标文件
2. 重命名为对应的文件名
3. 或者暂时注释掉 manifest.json 中的图标配置
