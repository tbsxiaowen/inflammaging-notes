# YouTube 双语字幕插件

在 YouTube 视频的**英语字幕**（含自动生成）下方，同步显示**中文翻译**。

## 功能

- 自动检测当前显示的英文字幕文本
- 优先使用 **Google 翻译**（非官方接口），备用 Lingva / LibreTranslate / MyMemory
- 在页面**右侧**显示独立翻译面板，与英文字幕同步更新（不依赖 YouTube 字幕 DOM）
- 翻译结果会缓存，重复句子不重复请求
- 可通过扩展弹出菜单开关「显示中文翻译」

## 使用方法

1. **安装扩展**
   - 打开 Chrome，进入 `chrome://extensions/`
   - 开启右上角「开发者模式」
   - 点击「加载已解压的扩展程序」，选择本目录 `YouTube双语字幕插件`

2. **在 YouTube 上看视频**
   - 打开任意 YouTube 视频
   - 点击播放器右下角 **CC（字幕）** 按钮，选择 **英语** 或 **英语（自动生成）**
   - 英文字幕出现后，右侧会出现「中文翻译」面板，内容与当前字幕同步

3. **开关**
   - 点击浏览器工具栏中的扩展图标，勾选/取消「在英语字幕下显示中文翻译」即可启用或关闭

## 技术说明

- **Manifest V3**，内容脚本仅注入 `https://www.youtube.com/*`
- 通过监听字幕 DOM（`ytp-caption-segment` / `caption-window-*`）变化获取当前字幕文本
- 翻译在 Service Worker 中请求 Google 翻译等接口，避免内容脚本跨域
- 中文显示在页面右侧的**独立浮动面板**中（固定于视口右侧中部），不依赖 YouTube 字幕区域

## 翻译 API

- **优先**：**Google 翻译**（非官方接口 `translate.googleapis.com`，与网页版同源，无需 API Key）。
- **备用**：Lingva 公开实例（后端为 Google 翻译）→ LibreTranslate → MyMemory。
- 若 Google 或 Lingva 不可用，会自动依次尝试其余源；若需更高额度或更稳定，可自行在 `background.js` 中替换或增加其他翻译 API。

## 注意事项

- 必须先打开 **英文字幕（CC）**，插件才会检测并显示中文
- 仅针对**英语 → 中文**；若字幕已是中文，不会重复翻译
- 依赖网络请求翻译，首次或新句子会有短暂延迟

## 不显示中文时如何排查

1. **确认已开启英文字幕**  
   播放器右下角点击 **CC（字幕）** → 选择 **英语** 或 **英语（自动生成）**，并确认画面上已有英文字幕。

2. **确认扩展已开启**  
   点击扩展图标，确保「在英语字幕下显示中文翻译」已勾选。

3. **打开调试模式**  
   在弹出菜单中勾选「调试模式」，刷新 YouTube 视频页，按 F12 打开开发者工具 → 切到 **Console**。  
   - 若出现 `[YouTube双语字幕] 已监听字幕节点`，说明已找到字幕区域。  
   - 若出现 `[YouTube双语字幕] 字幕文本: ...` 和 `翻译结果: ...`，说明翻译在运行。  
   - 若没有任何 `[YouTube双语字幕]` 日志，可能是页面结构变化导致找不到字幕节点，可把控制台截图反馈给开发者。

4. **检查网络**  
   翻译依赖 Google 翻译等外网接口；若请求失败，控制台会看到 `翻译请求错误`。
