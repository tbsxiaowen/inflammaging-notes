# YouTube双语字幕插件

🎥 实时双语字幕 + Google翻译，让YouTube视频更易理解！

## ✨ 功能特点

- **实时字幕捕获** - 自动获取YouTube原生字幕
- **Google翻译** - 实时翻译成中文
- **双语显示** - 英文原文 + 中文翻译
- **时间戳** - 显示字幕时间
- **可拖拽** - 自由移动字幕窗口
- **响应式设计** - 支持移动端和桌面端

## 🚀 安装方法

### Edge浏览器安装

1. **下载插件文件**
   - 将所有文件下载到本地文件夹
   - 确保文件结构完整

2. **打开Edge扩展管理**
   - 在Edge地址栏输入：`edge://extensions/`
   - 或者点击菜单 → 扩展 → 管理扩展

3. **启用开发者模式**
   - 打开"开发人员模式"开关

4. **加载插件**
   - 点击"加载解压缩的扩展"
   - 选择包含插件文件的文件夹

5. **确认安装**
   - 插件图标应该出现在工具栏
   - 显示"YouTube双语字幕"

## 📱 使用方法

### 基本使用

1. **访问YouTube**
   - 打开任意YouTube视频页面
   - 确保视频有字幕（CC按钮）

2. **启用插件**
   - 点击浏览器工具栏的插件图标
   - 确认插件状态为"已启用"

3. **观看双语字幕**
   - 插件会自动显示双语字幕窗口
   - 英文原文 + 中文翻译

### 高级功能

- **拖拽移动** - 点击头部拖拽字幕窗口
- **显示/隐藏** - 点击👁️按钮切换字幕内容
- **清空历史** - 点击🗑️按钮清空字幕记录
- **关闭窗口** - 点击❌按钮关闭字幕窗口

## ⚙️ 配置选项

### 默认设置

- **自动翻译** - 开启
- **目标语言** - 中文 (zh)
- **源语言** - 自动检测
- **显示时间戳** - 开启
- **最大历史记录** - 100条
- **窗口位置** - 右上角

### 自定义设置

1. 点击插件图标打开设置
2. 调整翻译语言、显示选项等
3. 设置会自动保存

## ⚠️ 注意事项

1. **字幕要求** - 视频必须有YouTube原生字幕
2. **网络连接** - 需要网络连接进行翻译
3. **翻译延迟** - 翻译可能有1-2秒延迟
4. **浏览器兼容** - 仅支持Edge浏览器

## 🐛 常见问题

### Q: 插件不工作？
A: 检查以下几点：
- 是否在YouTube页面
- 视频是否有字幕
- 插件是否已启用
- 浏览器是否支持

### Q: 翻译不准确？
A: 这是正常现象：
- Google翻译是机器翻译
- 专业术语可能不准确
- 建议结合上下文理解

### Q: 字幕窗口消失？
A: 可能的原因：
- 页面刷新或导航
- 插件被禁用
- 浏览器扩展冲突
