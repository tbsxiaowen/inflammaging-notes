# 数据保护方案分析

## 🤔 你的担心：AI 误删除本地文件

这是一个**合理的担心**！确实有用户遇到过 AI 误操作删除文件的情况。

## ❌ 容器（Docker）对防止误删除的作用**有限**

### 容器的实际作用
- ✅ **环境隔离**：隔离 Python 版本和依赖包
- ✅ **部署一致性**：在不同机器上运行相同的环境
- ✅ **资源限制**：限制 CPU、内存使用
- ⚠️ **文件系统保护**：**有限**，容器仍然可以访问挂载的目录

### 容器的局限性
1. **如果挂载了你的项目目录**，容器内的代码**仍然可以删除**挂载目录中的文件
2. **容器主要用于环境隔离，不是文件保护**
3. **增加复杂度**：需要 Docker 引擎，学习成本高

## ✅ 更实用的保护方案（推荐）

### 方案 1：Git 版本控制（**最重要**）⭐⭐⭐⭐⭐

**为什么最有效？**
- ✅ 所有文件变更都有历史记录
- ✅ 误删除可以轻松恢复
- ✅ 可以查看每次修改的详细内容
- ✅ 免费、简单、行业标准

**快速设置：**
```bash
cd ~/土拨鼠的蛋
git init
git add .
git commit -m "初始提交：保护所有文件"
```

**日常使用：**
```bash
# 每次修改后提交
git add .
git commit -m "更新爬虫代码"

# 如果误删文件，恢复
git checkout HEAD -- 被删除的文件路径
```

### 方案 2：Time Machine 自动备份（macOS 自带）⭐⭐⭐⭐

**为什么有效？**
- ✅ macOS 系统自带，无需配置
- ✅ 自动备份，无需手动操作
- ✅ 可以恢复任意时间点的文件
- ✅ 误删除可以轻松找回

**检查是否开启：**
```bash
# 系统设置 > Time Machine
# 确保已开启并连接备份磁盘
```

### 方案 3：定期手动备份 ⭐⭐⭐

**简单有效：**
```bash
# 创建备份脚本
#!/bin/bash
BACKUP_DIR="$HOME/备份/土拨鼠的蛋_$(date +%Y%m%d)"
cp -r ~/土拨鼠的蛋 "$BACKUP_DIR"
echo "备份完成：$BACKUP_DIR"
```

### 方案 4：文件权限保护 ⭐⭐

**限制删除权限：**
```bash
# 给重要目录添加只读权限（谨慎使用）
chmod -R 555 ~/土拨鼠的蛋/重要文件夹
```

**注意**：这会影响正常使用，不推荐。

### 方案 5：使用 Cursor 的安全设置 ⭐⭐⭐⭐

**Cursor 编辑器设置：**
- ✅ 在设置中启用"确认删除操作"
- ✅ 使用 Git 集成，每次删除前会提示
- ✅ 启用文件历史记录功能

## ⚠️ 重要警告：版本控制的局限性

### 版本控制只能保护项目目录内的文件

**严重风险场景：**
- ❌ AI 误删了 `/Users/` 下的其他目录（如 `~/Documents/`, `~/Desktop/`）
- ❌ AI 误删了系统文件（如 `/System/`, `/Library/`）
- ❌ AI 因为路径错误删除了项目外的文件
- ❌ 代码中的 bug 导致删除了项目外的文件

**版本控制无法保护这些情况！**

## 🛡️ 系统级保护方案（必须）

### 方案 A：Time Machine 自动备份（**最重要**）⭐⭐⭐⭐⭐

**为什么必须开启？**
- ✅ **系统级保护**：保护整个系统，不仅仅是项目目录
- ✅ **自动备份**：无需手动操作，每小时自动备份
- ✅ **可以恢复任意文件**：包括系统文件、其他目录的文件
- ✅ **时间点恢复**：可以恢复到任意时间点
- ✅ **macOS 自带**：无需额外软件

**如何设置：**
1. 打开"系统设置" > "Time Machine"
2. 连接外部硬盘（建议至少 2 倍系统盘大小）
3. 开启 Time Machine
4. 选择备份磁盘

**如果误删系统文件：**
1. 打开 Time Machine
2. 找到被删除的文件
3. 点击"恢复"

### 方案 B：限制 AI 的操作范围 ⭐⭐⭐⭐

**在 Cursor 中设置工作区限制：**
- ✅ 只打开项目目录（`~/土拨鼠的蛋`）
- ✅ 不要给 AI 访问其他目录的权限
- ✅ 在指令中明确指定文件路径

**安全的指令示例：**
```bash
# ✅ 安全：明确指定项目内的路径
"删除 ~/土拨鼠的蛋/我的爬虫/output/ 中的临时文件"

# ❌ 危险：模糊的指令
"清理一下临时文件"
"删除所有日志文件"
```

### 方案 C：使用沙箱环境运行代码 ⭐⭐⭐

**限制 Python 脚本的文件访问：**

创建安全运行脚本 `safe_run.py`：
```python
#!/usr/bin/env python3
"""安全运行脚本，限制文件访问范围"""
import os
import sys
from pathlib import Path

# 只允许访问项目目录
ALLOWED_DIR = Path.home() / "土拨鼠的蛋"
ALLOWED_DIR = ALLOWED_DIR.resolve()

def check_path_safe(path):
    """检查路径是否在允许的目录内"""
    try:
        resolved = Path(path).resolve()
        return str(resolved).startswith(str(ALLOWED_DIR))
    except:
        return False

# 重写危险的文件操作函数
original_remove = os.remove
original_rmdir = os.rmdir

def safe_remove(path):
    if not check_path_safe(path):
        raise PermissionError(f"不允许删除项目外的文件: {path}")
    return original_remove(path)

def safe_rmdir(path):
    if not check_path_safe(path):
        raise PermissionError(f"不允许删除项目外的目录: {path}")
    return original_rmdir(path)

os.remove = safe_remove
os.rmdir = safe_rmdir

# 运行用户脚本
if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("用法: safe_run.py <脚本文件>")
        sys.exit(1)
    
    script_path = sys.argv[1]
    exec(open(script_path).read())
```
